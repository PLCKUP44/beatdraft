# 🎵 BeatDraft

Fantasy Music Platform - Collect artist cards and compete based on real Spotify data.

## 📁 Project Structure

```
beatdraft/
├── frontend/          # Frontend (HTML/JS/CSS)
│   └── index.html
└── backend/           # Backend API (Node.js + PostgreSQL)
    ├── server.js
    ├── routes/
    ├── services/
    └── README.md
```

## 🚀 Quick Start

### Frontend Only (Static)
1. Open `frontend/index.html` in browser
2. Or deploy to GitHub Pages (automatic)

### Full Stack (with Backend)
1. Follow instructions in `backend/README.md`
2. Deploy backend to Render
3. Update frontend API_URL

## 📖 Documentation

- **Frontend**: Just open `frontend/index.html`
- **Backend**: See `backend/README.md` for setup
- **Deploy**: See `backend/DEPLOY.md` for Render deployment

## 🔧 Tech Stack

**Frontend:**
- HTML5 / CSS3 / Vanilla JavaScript
- Responsive design
- No framework dependencies

**Backend:**
- Node.js + Express
- PostgreSQL database
- Spotify Web API integration
- JWT authentication
