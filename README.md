# 🎵 BeatDraft

**Fantasy music platform** - Schiera i tuoi artisti preferiti e vinci competizioni settimanali!

## 🎮 Cos'è BeatDraft?

BeatDraft è una piattaforma fantasy music dove puoi:
- 🃏 Collezionare carte degli artisti musicali
- 🏆 Partecipare a competizioni settimanali
- 📊 Guadagnare punti dalle performance reali degli artisti
- 💎 Scambiare carte rare e preziose

## ✨ Features

- **5 Categorie di artisti**: Leggendario, Mondiale, Grande, Emergente, Sconosciuto
- **4 Rarità**: Common, Rare, Epic, Platinum
- **Sistema di scoring**: Basato su crescita ascoltatori + chart position
- **Competizioni live**: 14 giorni, premi esclusivi
- **Marketplace**: Acquista e vendi carte
- **Classifiche**: Confrontati con altri giocatori
